Getting started (5 minutes)

  1. Get an AI API key. The assistant needs a key for one AI service. We recommend Anthropic Claude: fast and accurate for tickets. OpenAI or Google Gemini also work.
    Start today: get a free Gemini key yourself (no IT request)

    You can make a Google Gemini key in 2 minutes with your Lambda Google account, and use it until IT gives you a Claude or OpenAI (ChatGPT) key.

    1. Open aistudio.google.com/apikey and sign in with your Lambda Google account (@lambdal.com or @lambda.ai). Accept the terms if it asks.
    2. Click Create API key. If it asks for a project, choose Create API key in new project.
    3. Click Copy next to the key. It starts with AIza.
    4. Click (it selects Gemini Flash-Lite (latest): fast, with the free tier's highest limits), paste the key in Gemini API key below, then Save. Test AI checks that it works.

    ⚠️ On the free tier Google may use what you send to improve its products, and there's a daily limit. Turn on Privacy mode (Privacy tab) so names, IPs and serials are replaced before anything is sent. When IT gives you a Claude or OpenAI key, switch the provider and paste it: you can delete the Gemini key at aistudio.google.com/apikey.

    If the page says AI Studio isn't available for your account, it's turned off for Lambda accounts: use the IT request below instead. Don't use a personal Google account for work tickets.

    I don't have a key: ask IT

    Send this to IT (Slack or a ticket). You can change the provider if your team uses a different one.

    Treat the key like a password: paste it only into this page, never into Slack, Jira or email.

  2. Install the helper tools (ping, BMC). Open Terminal (press ⌘ Space, type Terminal, press Return), paste this command with ⌘ V and press Return. Open PowerShell (press the Windows key, type PowerShell, press Enter), paste this command with Ctrl V (or right-click) and press Enter. It asks before installing anything.
    It finds the lambda-rackside folder wherever you put it (Desktop, Downloads…). If it says the folder wasn't found, type bashpowershell -ExecutionPolicy Bypass -File and a space, drag setup.shsetup.ps1 from the folder into the window, add a space and the extension ID (), then press Enter.
  3. Paste your key below, click Load models, then Save. Open any Jira ticket and click the Lambda icon in Chrome's toolbar.

Back up or move your settings

Keep a copy, move to a new computer, or share your team's setup (Jira fields, team notes, catalog link) without the keys. Saves what you last saved with Save. Loading a file changes only the settings in it.

Updates

Checks the lambda-rackside repo on GitHub with your GitHub login in Chrome. The repo is private, so you need access to it. Chrome also checks every 2 hours: a new version shows a red NEW badge on the toolbar icon, one notification, and a 🆕 banner in the panel.

Privacy

Before a ticket is sent, the values below are replaced with placeholders like [IP-1] or [PERSON-2]. The AI works with the placeholders, and the real values are put back into the brief on this computer, so you still see them. Passwords, tokens and API keys found in tickets are always removed in privacy mode. Not needed with a Local model: nothing leaves your computer.

Parts catalog

The Parts card matches part numbers from the ticket, NetBox and the BMC against this sheet, shows each part's Lambda P/N first (with SKU, MPN and description), lets you search it, and opens the sheet on the part's row so you can confirm it. Paste any catalog link that opens in Google Sheets (a Google Sheet or an Excel file in Drive); you need access to it, and it's read once a day. Clear the field to go back to the default catalog. When you ask the AI chat about parts, the catalog rows that fit your question (about 30) are sent with it so it can answer with real Lambda P/Ns.

BMC logins, health & power

Check health asks for the BMC password: copy the BMC IP (there's a button), find it in 1Password (), copy the password and paste it into the panel. The check starts as soon as you paste. The password is kept in memory until you close the panel, never saved or sent to the AI.
Used by the Open BMC button. {ip} is replaced with the BMC IP. Change it if your BMCs use http or a port, e.g. http://{ip}:8080.

NetBox & Podcrawler

Shows NetBox status, location, serial, BMC IP and cabling, and warns when the ticket and NetBox disagree.
By default the extension uses your NetBox login in Chrome, so no token is needed. If that doesn't work, create a read-only token in NetBox (your profile → API Tokens) and paste it here.
The Open Podcrawler button opens this and copies the hostname, so you can paste it into the search.

People

With Slack in Chrome, the extension opens your chat with that person (it uses Slack's own search in your Slack tab; nothing is sent). If Slack is already open in a Chrome tab, that tab is used either way. The desktop app can't be controlled, so there the name is copied: press and paste.
