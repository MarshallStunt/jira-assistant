Getting started (5 minutes)

  1. Get an AI API key. The assistant needs a key for one AI service. We recommend Anthropic Claude: fast and accurate for tickets. OpenAI or Google Gemini also work.
    I don't have a key: ask IT

    Send this to IT (Slack or a ticket). You can change the provider if your team uses a different one.

    Treat the key like a password: paste it only into this page, never into Slack, Jira or email.

  2. Install the helper tools (ping, BMC). Open Terminal (press ⌘ Space, type Terminal, press Return), paste this command with ⌘ V and press Return. Open PowerShell (press the Windows key, type PowerShell, press Enter), paste this command with Ctrl V (or right-click) and press Enter. It asks before installing anything.
    If you put the jira-assistant folder somewhere other than your Desktop, change the path in the command.
  3. Paste your key below, click Load models, then Save. Open any Jira ticket and click the Lambda icon in Chrome's toolbar.
